# Guía interactiva de Cyberpunk 2077 (2.5 + Phantom Liberty)

Guía en español para seguir una partida nueva y completar el contenido del juego base y de Phantom Liberty. Incluye listas interactivas, barra de progreso, rutas recomendadas y capturas enlazadas a sus fuentes.

## Uso

Abre `index.html` en un navegador. Las marcas de las casillas se guardan automáticamente en el almacenamiento local de ese navegador; no se sincronizan entre dispositivos.

## Publicar con GitHub Pages

1. Crea un repositorio en GitHub y sube `index.html` y `README.md` a la raíz del repositorio.
2. Abre **Settings → Pages**.
3. En **Build and deployment**, elige **Deploy from a branch**.
4. Selecciona la rama `main` y la carpeta `/(root)`, y pulsa **Save**.
5. Cuando termine la publicación, GitHub mostrará la dirección de la página en esa sección.

## Imágenes y atribución

Las capturas de pantalla se cargan desde las páginas de sus fuentes; el repositorio no las copia ni las aloja. Por eso requieren conexión a internet y pueden dejar de mostrarse si cambia la dirección o disponibilidad de la fuente. Cada imagen de la guía enlaza a la página de origen.
